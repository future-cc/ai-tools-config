# Multica 当前工作流摘要

## 小队任务启动

小队任务第一次运行时，工作流总管只做最低限度读取，然后输出：

- `WORKFLOW_VERSION`
- 任务理解、范围和排除项
- 验收标准、风险和依赖
- 必调用与条件调用智能体
- 调用顺序、职责、触发条件和文件权限
- 预期产物

随后等待人工批准。第一道批准只允许已批准的调研师或规划师生成规划文档，不授权技术审核、代码修改、测试或完成任务。

## 计划审核

```text
Codex 规划师生成 PLAN.md
→ 人工审核 PLAN_VERSION
→ 方案与实现审核员技术审核
→ 生成 IMPLEMENTATION.md / TEST_PLAN.md
→ 技术审核实施文档
→ OpenCode 执行
→ 通用测试员测试
→ 最终代码审核
```

`PLAN.md` 任何修改都会使旧人工批准失效，必须升级版本并重新人工审核。实施文档默认由技术审核员审核；只有改变范围、架构、接口、数据结构、用户可见行为或涉及高风险操作时，才重新请求人工审核。

## 结果和循环

审核和测试只使用 `PASS`、`CHANGES_REQUIRED`、`BLOCKED`。修订、修复和复测最多两轮，超过后暂停并等待人工决策。
